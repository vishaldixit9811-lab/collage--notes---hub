C Programming — Unit 1

Fundamentals of C Programming

Easy English notes for BCA students.

1. Introduction to C

C is a general-purpose programming language. It is used to develop system software and application programs.

2. Structure of a C Program

A C program commonly contains header files, the main() function, declarations, statements and a return statement. 

#include <stdio.h>

int main(void)
{
    printf("Hello World");

    return 0;
}

3. Variables and Data Types

A variable is a named memory location used to store a value. 

int marks = 90;
float percentage = 85.5f;
char grade = 'A';

4. Operators

Operators perform operations on values and variables.

Examples: +, -, *, / and %. 

int a = 10;
int b = 5;

printf("%d", a + b);

5. Conditional Statements

Conditional statements execute code according to a condition. 

int marks = 60;

if (marks >= 40)
{
    printf("Pass");
}
else
{
    printf("Fail");
}
