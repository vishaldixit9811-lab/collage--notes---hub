C Programming — Unit 2

Arrays and Strings

Easy English notes and programming examples for BCA students.

1. What is an Array?

An array is a collection of elements of the same data type stored under one name. Each element is accessed using an index.

Example: An array can store marks of five students.

int marks[5] = {70, 80, 65, 90, 75};

2. One-Dimensional Array

A one-dimensional array stores elements in a single sequence. In C, array indexing starts at 0. 

#include <stdio.h>

int main(void)
{
    int numbers[3] = {10, 20, 30};

    printf("%d", numbers[0]);

    return 0;
}

Output: 10

3. Two-Dimensional Array

A two-dimensional array stores data in rows and columns. It is commonly used to represent a matrix. 

int matrix[2][2] = {
    {1, 2},
    {3, 4}
};

4. What is a String?

A string in C is a sequence of characters ending with the null character, written as '\0'. 

char name[] = "Vishal";

5. Common String Functions

The string.h header provides functions for working with strings.

  • strlen() — finds the string length.
  • strcpy() — copies a string.
  • strcmp() — compares two strings.
  • strcat() — joins two strings.

These functions are declared in the <string.h> header.

C Programming — Unit 2

Arrays and Strings

Easy English notes for BCA students.

1. What is an Array?

An array is a collection of elements of the same data type stored under one name.

Example:

int marks[5] = {70, 80, 65, 90, 75};

Here, marks is an integer array containing five elements. Array indexing starts at 0.

2. One-Dimensional Array

A one-dimensional array stores elements in a single sequence. 

#include <stdio.h>

int main(void)
{
    int numbers[3] = {10, 20, 30};

    printf("%d\n", numbers[0]);
    printf("%d\n", numbers[1]);
    printf("%d\n", numbers[2]);

    return 0;
}

Output:

10
20
30

3. Two-Dimensional Array

A two-dimensional array stores data in rows and columns. It is useful for representing tables and matrices. 

int matrix[2][2] = {
    {1, 2},
    {3, 4}
};

4. What is a String?

In C, a string is a sequence of characters terminated by the null character '\0'. 

char name[] = "Vishal";

The compiler includes the terminating null character in this array.

5. Common String Functions

The string.h header provides common string functions.

  • strlen() — finds string length.
  • strcpy() — copies a string.
  • strcat() — joins strings.
  • strcmp() — compares strings.
#include <stdio.h>
#include <string.h>

int main(void)
{
    char name[] = "Hello";

    printf("%zu", strlen(name));

    return 0;
}

Output: 5
